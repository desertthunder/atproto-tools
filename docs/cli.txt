atp(1)			    General Commands Manual			atp(1)

NAME
       atp - Inspect and maintain AT Protocol data from a POSIX-friendly CLI

SYNOPSIS
       atp [--config] [-h|--help] <subcommands>

DESCRIPTION
       Inspect AT Protocol actors, synchronize Lexicon schemas, export
       at.margin notes, and build Bluesky follow reports.

       The CLI reads configuration from ~/.config/atproto-tools/config.toml by
       default. Pass --config to use another file for a single invocation.

OPTIONS
       --config <PATH>
	      Read configuration from PATH instead of
	      ~/.config/atproto-tools/config.toml

       -h, --help
	      Print help (see a summary with '-h')

SUBCOMMANDS
       atp-info(1)
	      Fetch profile metadata, DID document data, and repository
	      information for an actor

       atp-config(1)
	      Read or update CLI configuration values

       atp-lexicons(1)
	      Sync Lexicon JSON and generate serde-compatible Rust models

       atp-margin(1)
	      Export and transform at.margin records

       atp-bsky(1)
	      Fetch, cache, and analyze Bluesky app data

       atp-help(1)
	      Print this message or the help of the given subcommand(s)

				     atp				atp(1)

NAME
       atp-config-set - Set a supported config field and persist it to disk

SYNOPSIS
       atp config set [-h|--help] <FIELD> <VALUE>

DESCRIPTION
       Set a supported config field and persist it to disk

OPTIONS
       -h, --help
	      Print help (see a summary with '-h')

       <FIELD>
	      Config field to update.

	      Supported fields are identity.identifier,
	      link-digest.follow-poll-cron, link-digest.limit,
	      link-digest.min-score, link-digest.min-shares,
	      services.public-api-base, and services.plc-directory-base.

	      Possible values:

		     • identity.identifier

		     • link-digest.follow-poll-cron

		     • link-digest.limit

		     • link-digest.min-score

		     • link-digest.min-shares

		     • services.public-api-base

		     • services.plc-directory-base

       <VALUE>
	      New value for FIELD. Numeric fields are validated before the
	      config file is written

atp-lexicons-sync(1)	    General Commands Manual	  atp-lexicons-sync(1)

NAME
       atp-lexicons-sync - Pull selected Lexicon JSON files from a git
       repository at a pinned commit

SYNOPSIS
       atp lexicons sync [--repo] <--commit> [--source-path] [--dest] [--file]
       [-h|--help] <TOOL>

DESCRIPTION
       Pull selected Lexicon JSON files from a git repository at a pinned
       commit

OPTIONS
       --repo <REPO>
	      Git repository URL, host/path, or GitHub owner/name. Overrides
	      the tool preset source repo

       --commit <COMMIT>
	      Commit hash to fetch from. Pinning the commit keeps generated
	      models reproducible

       --source-path <SOURCE_PATH>
	      Directory inside the source repository that contains Lexicon
	      JSON files

       --dest <DEST>
	      Local destination directory for synced Lexicon JSON files

       --file <FILES>
	      Lexicon filename to sync. Repeat to replace the preset file list

       -h, --help
	      Print help

       <TOOL> Tool preset to sync. The preset selects default repo, source
	      path, destination, and files

	      Possible values:

		     • bsky

		     • margin

		     • semble

		     • tangled

			      atp-lexicons-sync 	  atp-lexicons-sync(1)

atp-bsky-link-digest(1)     General Commands Manual    atp-bsky-link-digest(1)

NAME
       atp-bsky-link-digest - Generate a Markdown digest of external links
       shared by followed accounts

SYNOPSIS
       atp bsky link-digest [--actor] [--since] [--until] [--limit]
       [--min-score] [--min-shares] [--feed-limit] [--max-pages]
       [--refresh-follows] [-h|--help]

DESCRIPTION
       Generate a Markdown digest of external links shared by followed
       accounts

OPTIONS
       --actor <HANDLE_OR_DID>
	      Handle or DID whose follows should be inspected. Defaults to
	      identity.identifier in config.toml

       --since <ISO_DATETIME>
	      Only include posts at or after this ISO datetime

       --until <ISO_DATETIME>
	      Only include posts before this ISO datetime

       --limit <N>
	      Maximum links to include. Defaults to link-digest.limit

       --min-score <N>
	      Minimum bookmark + repost + like score required for a link.
	      Defaults to link-digest.min-score

       --min-shares <N>
	      Minimum distinct followed accounts that must share the same
	      link. Defaults to link-digest.min-shares

       --feed-limit <N> [default: 100]
	      Number of author-feed posts to fetch per page

       --max-pages <N> [default: 5]
	      Maximum author-feed pages to fetch per follow

       --refresh-follows
	      Ignore the cached follow list and fetch fresh follows before
	      building the digest

       -h, --help
	      Print help

			     atp-bsky-link-digest      atp-bsky-link-digest(1)


atp-bsky-follows(1)	    General Commands Manual	   atp-bsky-follows(1)

NAME
       atp-bsky-follows - Fetch followed accounts and each account's latest
       original post

SYNOPSIS
       atp bsky follows [--actor] [--limit] [--sort] [--asc] [--desc] [--sa]
       [--sd] [--refresh] [--json] [-h|--help]

DESCRIPTION
       Fetch followed accounts and each account's latest original post

OPTIONS
       --actor <HANDLE_OR_DID>
	      Handle or DID to inspect. Defaults to identity.identifier in
	      config.toml

       --limit <N>
	      Only inspect the first N follows after fetching or loading the
	      follow list

       --sort <FIELD>
	      Sort rows by field. Defaults to last-post-at

	      Possible values:

		     • handle

		     • did

		     • profile-url

		     • last-post-at

		     • last-post-rkey

		     • last-post-url

       --asc  Sort in ascending order. This is the default direction

       --desc Sort in descending order

       --sa <FIELD>
	      Sort rows by FIELD in ascending order. Shorthand for --sort
	      FIELD --asc

	      Possible values:

		     • handle

		     • did

		     • profile-url

		     • last-post-at

		     • last-post-rkey

		     • last-post-url

       --sd <FIELD>
	      Sort rows by FIELD in descending order. Shorthand for --sort
	      FIELD --desc

	      Possible values:

		     • handle

		     • did

		     • profile-url

		     • last-post-at

		     • last-post-rkey

		     • last-post-url

       --refresh
	      Ignore any matching cache file and fetch fresh data from Bluesky

       --json Print the complete cached report as formatted JSON instead of a
	      table

       -h, --help
	      Print help

			       atp-bsky-follows 	   atp-bsky-follows(1)
